## 1. Phân Tích Hệ Thống & Điểm Đòn Bẩy (Systems Thinking Analysis)

> 🌐 **SYSTEMS ANALYSIS**
> * **Phạm vi (Scope):** Ranh giới FFI giữa Rust Microkernel (`theus_core::Transaction`, `TheusEngine`) và Python Wrapper (`theus.engine.TheusEngine`, `StateView`).
> * **Động lực học (Dynamics):** Vòng lặp phản hồi củng cố (R1) sinh ra do quản lý máy trạng thái phân mảnh: mỗi lần vá một kẽ hở cục bộ (loại bỏ deadlock) lại mở ra một kẽ hở đồng thời khác (kẹt trạng thái qua toán tử `?`, re-entrancy ở `__enter__`).
> * **Nguyên nhân cấu trúc (Root Structure):** Python context manager ép `__exit__(&self)` nhận tham chiếu chia sẻ thay vì move semantics (`self`), buộc dùng `Mutex`. Việc rải rác lệnh gán trạng thái trước mỗi lệnh `?` khiến luồng điều khiển dễ bị rò rỉ.
> * **Điểm đòn bẩy (Leverage Point):**
>   1. **Đóng gói phạm vi thực thi (Enclosed Execution Scope):** Đưa toàn bộ các bước commit và validate vào một closure trả về `PyResult<Py<State>>`. Mọi lỗi `?` đều hội tụ về một điểm thoát duy nhất để chuyển `Failed`, kết hợp `into_inner()` trích xuất guard khi lock bị ngộ độc, triệt tiêu 100% nguy cơ kẹt trạng thái `Committing`.
>   2. **Bảo vệ tiền điều kiện (Precondition Gate):** `__enter__` từ chối mọi trạng thái khác `Unopened`.
>   3. **Đồng bộ tự phục hồi theo từng trường (Per-Field Fallback Sync):** Nếu Pydantic/dataclass model validate lỗi trên một trường, tự động fallback về native proxy của trường đó, bảo đảm `_context` luôn phản ánh dữ liệu mới nhất.
>   4. **Circuit Breaker minh bạch:** Phát `warnings.warn` và gắn cờ `_is_stale = True` khi sync thất bại liên tiếp 3 lần.

#### 2. Tách hàm dùng chung `detect_field_conflict`:

> **[Ghi chú triển khai]** Chữ ký thực tế mở rộng thêm `heavy_dict` so với thiết kế ban đầu — cải tiến cần thiết để tránh bỏ sót conflict ở vùng heavy.

```rust
fn detect_field_conflict(
    current_state: &State,
    start_ver: u64,
    data_dict: Option<&Bound<'_, PyDict>>,
    heavy_dict: Option<&Bound<'_, PyDict>>,
) -> PyResult<Option<(u64, u64)>> {
    let current_version = current_state.version;
    if current_version == start_ver {
        return Ok(None);
    }

    let check_dict = |dict_opt: Option<&Bound<'_, PyDict>>| -> PyResult<bool> {
        if let Some(d) = dict_opt {
            for (zone_k, zone_v) in d.iter() {
                let zone_key = zone_k.extract::<String>()?;
                if let Ok(inner_dict) = zone_v.downcast::<PyDict>() {
                    for (ik, _) in inner_dict.iter() {
                        let inner_key = ik.extract::<String>()?;
                        let field_path = format!("{zone_key}.{inner_key}");
                        if let Some(last_ver) = current_state.key_last_modified.get(&field_path) {
                            if *last_ver > start_ver {
                                return Ok(false);
                            }
                        }
                    }
                } else if let Some(last_ver) = current_state.key_last_modified.get(&zone_key) {
                    if *last_ver > start_ver {
                        return Ok(false);
                    }
                }
            }
        }
        Ok(true)
    };

    if !check_dict(data_dict)? {
        return Ok(Some((start_ver, current_version)));
    }
    if !check_dict(heavy_dict)? {
        return Ok(Some((start_ver, current_version)));
    }

    Ok(None)
}
```

#### 3. Chuyển trạng thái an toàn trong `__enter__`:
```rust
fn __enter__(mut slf: PyRefMut<Self>, py: Python) -> PyResult<Py<Self>> {
    slf.start_time = Some(Instant::now());
    let engine = slf.engine.bind(py);
    let engine_borrow = engine.borrow();
    let current_ver = engine_borrow.state.bind(py).borrow().version;
    drop(engine_borrow);

    let mut guard = slf.lifecycle.lock().unwrap_or_else(|e| e.into_inner());

    // ĐÒN BẨY: Chặn đứng re-entrancy
    if *guard != TransactionLifecycle::Unopened {
        return Err(ContextError::new_err(format!(
            "Cannot enter transaction: transaction is already {:?}",
            *guard
        )));
    }

    *guard = TransactionLifecycle::Active { start_version: current_ver };
    Ok(slf.into())
}
```

#### 4. Thực thi an toàn trong `__exit__`:
```rust
fn __exit__(
    &self,
    py: Python,
    exc_type: Option<PyObject>,
    _exc_value: Option<PyObject>,
    _traceback: Option<PyObject>,
) -> PyResult<()> {
    // BƯỚC 1: Thẩm định và lấy start_version trong phạm vi khoá hẹp
    let start_ver = {
        let mut guard = self.lifecycle.lock().unwrap_or_else(|e| e.into_inner());

        match *guard {
            TransactionLifecycle::Unopened => {
                return Err(ContextError::new_err(
                    "Transaction commit attempted on unopened transaction (missing __enter__)",
                ));
            }
            TransactionLifecycle::Committed => {
                return Ok(()); // Replay an toàn
            }
            TransactionLifecycle::Committing => {
                return Err(ContextError::new_err(
                    "Transaction commit is already in progress",
                ));
            }
            TransactionLifecycle::Aborted => {
                return Err(ContextError::new_err(
                    "Transaction cannot be re-exited: transaction was aborted",
                ));
            }
            TransactionLifecycle::Failed => {
                return Err(ContextError::new_err(
                    "Transaction cannot be committed: previous commit attempt failed",
                ));
            }
            TransactionLifecycle::Active { start_version } => {
                if exc_type.is_some() {
                    *guard = TransactionLifecycle::Aborted;
                    return Ok(());
                }
                *guard = TransactionLifecycle::Committing;
                start_version
            }
        }
    }; // Khoá nhả tại đây — Zero-Deadlock Scope

    // BƯỚC 2: ĐÒN BẨY — Enclosed Execution Scope
    let execute_commit = || -> PyResult<Py<State>> {
        // 2.1. Timeout check
        if let Some(start) = self.start_time {
            #[allow(clippy::cast_possible_truncation)]
            if start.elapsed().as_millis() as u64 > self.write_timeout_ms {
                return Err(WriteTimeoutError::new_err(format!(
                    "Transaction timed out after {}ms (limit {}ms)",
                    start.elapsed().as_millis(),
                    self.write_timeout_ms
                )));
            }
        }

        // 2.2. Shadow inference và commit deltas
        self.infer_shadow_deltas(py)?;
        self.commit(py)?;

        // 2.3. OCC Conflict Check
        let engine = self.engine.bind(py);
        let conflict = {
            let engine_borrow = engine.borrow();
            let current_state_bound = engine_borrow.state.bind(py);
            let current_state = current_state_bound.borrow();
            let pending = self.pending_data.bind(py);

            detect_field_conflict(&current_state, start_ver, &pending)?
        };

        if let Some((expected, found)) = conflict {
            return Err(ContextError::new_err(format!(
                "CAS Version Mismatch (Conflict Detected): Expected {expected}, Found {found} (Keys Changed)"
            )));
        }

        // 2.4. Update State
        let current_state_obj = engine.getattr("state")?;
        let new_state_obj = current_state_obj.call_method(
            "update",
            (self.pending_data.clone_ref(py), self.pending_heavy.clone_ref(py), self.pending_signal.clone_ref(py)),
            None,
        )?;

        // 2.5. Schema Validation (dùng map_err, không unwrap)
        {
            let engine_borrow = engine.borrow();
            let schema_guard = engine_borrow.schema.lock().map_err(|e| {
                ContextError::new_err(format!("Schema lock poisoned: {e}"))
            })?;
            if let Some(ref schema) = *schema_guard {
                let frozen_data = new_state_obj.getattr("data")?;
                let dict_data = frozen_data.call_method0("to_dict")?;
                if let Err(e) = schema.call_method1(py, "model_validate", (dict_data,)) {
                    return Err(crate::config::SchemaViolationError::new_err(format!("Schema Violation: {e}")));
                }
            }
        }

        new_state_obj.extract::<Py<State>>()
    };

    // BƯỚC 3: Đánh giá kết quả duy nhất (Không bao giờ kẹt ở Committing, kháng ngộ độc lock)
    let new_state = match execute_commit() {
        Ok(state) => state,
        Err(e) => {
            let mut guard = self.lifecycle.lock().unwrap_or_else(|err| err.into_inner());
            *guard = TransactionLifecycle::Failed;
            return Err(e);
        }
    };

    // BƯỚC 4: Ghi State vào Core (Point of Durability)
    let engine = self.engine.bind(py);
    {
        let mut engine_ref = engine.borrow_mut();
        engine_ref.state = new_state;
    }

    {
        let mut guard = self.lifecycle.lock().unwrap_or_else(|err| err.into_inner());
        *guard = TransactionLifecycle::Committed;
    }

    // BƯỚC 5: Post-Commit Signal Hook
    if let Ok(committed_state) = engine.getattr("state") {
        if let Err(e) = committed_state.call_method1("publish_signals", (self.pending_signal.clone_ref(py),)) {
            log::warn!("[TheusCore] Post-commit signal publish encountered error (state is durable): {e}");
        }
    }

    Ok(())
}
```

#### 1. Toàn văn `_sync_registry_from_core` có dự phòng per-field:
```python
def _sync_registry_from_core(self) -> bool:
    """Syncs current Rust Core state to NamespaceRegistry and Context object with per-field fallback."""
    if not hasattr(self, "_core"):
        return False
    try:
        data = self._core.state.data
        # 1. Sync Namespaces
        for name, ns_info in self._namespaces._namespaces.items():
            if name == "default":
                ns_info["data"] = {k: v for k, v in data.items() if k not in self._namespaces._namespaces}
            elif name in data:
                ns_info["data"] = data[name]

        # 2. Sync Context Fields (domain, global, etc.)
        if hasattr(self, "_context"):
            for field_name in ["domain", "domain_ctx", "global_ctx", "global"]:
                core_key = "global" if field_name in ("global_ctx", "global") else "domain"
                if core_key in data and hasattr(self._context, field_name):
                    curr_val = getattr(self._context, field_name)
                    if curr_val is not None:
                        model_cls = type(curr_val)
                        native_proxy = data[core_key]
                        raw_proxy = {
                            k: v for k, v in native_proxy.items()
                            if not k.startswith("_") and k not in ("transaction", "inner", "target")
                        }
                        clean_proxy = raw_proxy

                        try:
                            if hasattr(model_cls, "model_validate"):
                                new_obj = model_cls.model_validate(clean_proxy)
                            elif hasattr(model_cls, "parse_obj"):
                                new_obj = model_cls.parse_obj(clean_proxy)
                            elif dataclasses.is_dataclass(curr_val):
                                for f in dataclasses.fields(curr_val):
                                    if f.name in clean_proxy:
                                        incoming_val = clean_proxy[f.name]
                                        if incoming_val is None:
                                            existing_val = getattr(curr_val, f.name, None)
                                            if existing_val is not None and not isinstance(
                                                existing_val, (int, float, str, list, dict, bool)
                                            ):
                                                continue
                                        try:
                                            setattr(curr_val, f.name, incoming_val)
                                        except Exception:
                                            pass
                                new_obj = curr_val
                            else:
                                new_obj = native_proxy
                        except Exception:
                            # Khôi phục dự phòng per-field (v6/v7):
                            # Nếu validate model thất bại, gán trực tiếp native proxy
                            # kèm cảnh báo và cờ _sync_degraded để bảo đảm _context luôn có dữ liệu mới
                            # mà không làm mất tín hiệu về việc suy giảm kiểu.
                            warnings.warn(
                                f"Model validation failed during context sync for field '{field_name}'. "
                                "Falling back to native proxy (typing degraded).",
                                RuntimeWarning,
                                stacklevel=2,
                            )
                            object.__setattr__(self._context, "_sync_degraded", True)
                            new_obj = native_proxy

                        if new_obj is not None:
                            try:
                                object.__setattr__(new_obj, "_theus_proxy", native_proxy)
                            except Exception:
                                pass
                        object.__setattr__(self._context, field_name, new_obj)
        return True
    except Exception:
        return False
```

#### 2. Cập nhật `@property def state(self)` với Circuit Breaker:
```python
import warnings

@property
def state(self):
    """v3.3 Returns the Rust Core State object (Hybrid View)."""
    core_state = self._core.state
    curr_ver = core_state.version

    if getattr(self, "_cached_state_ver", -1) == curr_ver and hasattr(self, "_cached_state_view"):
        return self._cached_state_view

    # Reset fail count khi version thay đổi
    if getattr(self, "_cached_state_ver", -1) != curr_ver:
        object.__setattr__(self, "_sync_fail_count", 0)

    synced = self._sync_registry_from_core()
    is_stale = False

    if not synced:
        fail_count = getattr(self, "_sync_fail_count", 0) + 1
        object.__setattr__(self, "_sync_fail_count", fail_count)
        if fail_count >= 3:
            warnings.warn(
                f"StateView context sync degraded for version {curr_ver} after {fail_count} attempts; serving fallback state.",
                RuntimeWarning,
                stacklevel=2,
            )
            is_stale = True

    instance = self
    class StateView:
        _is_stale = is_stale
        @property
        def version(self): return core_state.version
        @property
        def data(self):
            class HybridData:
                def __getitem__(self, key):
                    val = getattr(instance._context, key, None)
                    if val is not None:
                        is_primitive = isinstance(val, (int, float, str, bool, list, dict, type(None), ContextGuard))
                        try:
                            from pydantic import BaseModel as PydanticBase
                            is_pydantic = isinstance(val, PydanticBase)
                        except ImportError:
                            is_pydantic = False
                        has_subscript = hasattr(type(val), "__getitem__") and not is_pydantic
                        if not is_primitive and not is_pydantic and not has_subscript:
                            proxy = getattr(val, "_theus_proxy", None)
                            return ContextGuard(
                                val,
                                allowed_inputs={"*"},
                                allowed_outputs={"*"},
                                _inner=proxy or val,
                                process_name="StateView"
                            )
                        return val
                    return core_state.data[key]
                def __getattr__(self, name): return getattr(core_state.data, name)
                def __repr__(self): return repr(core_state.data)
                def keys(self): return core_state.data.keys()
                def items(self): return core_state.data.items()
                def __iter__(self): return iter(core_state.data)
                def __len__(self): return len(core_state.data)
            return HybridData()

        def __getattr__(self, name): return getattr(core_state, name)
        def __repr__(self): return f"<StateView v{self.version}{' (stale)' if self._is_stale else ''}>"

    view = StateView()
    if synced or getattr(self, "_sync_fail_count", 0) >= 3:
        object.__setattr__(self, "_cached_state_ver", curr_ver)
        object.__setattr__(self, "_cached_state_view", view)
    return view
```
